## 📋 评分标准

### 1. 机械臂控制（7分）
- **7分**：末端位姿调整连续平滑无碰撞，完整执行"移动-定位暂停-精准复位"流程

## 🐛 故障排查

### 问题1：未接收到关节状态数据
**解决方法**：
- 确认 Isaac Sim 已启动
- 检查话题是否存在：`ros2 topic list | grep joint`
- 检查话题数据：`ros2 topic echo /joint_states --once`

### 问题2：夹爪不响应
**解决方法**：
- 检查夹爪控制器是否启用
- 确认话题名称正确：`gripper_controller`
- 检查夹爪限位范围

### 问题3：机械臂运动卡顿
**解决方法**：
- 检查系统资源占用
- 降低控制频率（修改 `steps = int(duration * 60)` 中的 60）
- 增加运动时间（增大 `duration` 参数）
